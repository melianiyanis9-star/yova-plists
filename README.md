# YOVA TOOL MobileGestalt Plists Repository

Official community and cloud repository for com.apple.MobileGestalt.plist templates used by YOVA TOOL.

## Supported Devices & Builds
- iPhone XS Max (iPhone11,6) - iOS 18.7.10 (Build 22H374)
- iPhone XR (iPhone11,8) - iOS 18.7.10 (Build 22H374)

## Automated Sync
Plists uploaded to @yova2flashbot on Telegram are automatically verified and synced to this repository.
